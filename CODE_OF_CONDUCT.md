# Code of Conduct

This project aims to be respectful, practical, and welcoming.

## Expected behavior

Please:

- be respectful and constructive
- focus feedback on ideas, code, and workflows
- assume good intent unless there is clear evidence otherwise
- help keep documentation approachable for new users
- keep technical disagreements specific and professional

## Unacceptable behavior

Please do not:

- harass or insult others
- use discriminatory or demeaning language
- post private information without permission
- derail discussions with repeated hostility
- deliberately make the project harder to use or maintain

## Maintainer responsibilities

Maintainers may edit, remove, or moderate comments, issues, pull requests, or discussions that violate this policy.

## Reporting problems

Use the maintainer contact path documented in the repository settings, or open a private moderation request if the platform supports it.
