Place example input files here when running the notebooks locally.

Expected files used by the notebooks:
- subject01_walk.mp4
- subject01_walk_grf.csv
- subject01_vicon.trc
- subject01_grf.csv
- Rajagopal.osim (or your preferred OpenSim model)

A copy of the uploaded `Mediapipe_Model.osim` is included for convenience.

The `Geometry/` directory contains OpenSim-compatible display geometry used by
the bundled full-body models. The full-body limb and HAT meshes came from the
user-provided FullBodyModel geometry folder. The individual cervical, thoracic,
and lumbar vertebra meshes are OpenSim/osim-rl geometry assets distributed under
the Apache License 2.0 by the OpenSim project.
